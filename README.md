# RENKAI
Aplikasi Android native (Kotlin + Jetpack Compose + Media3) untuk memutar stream HLS & DASH.

- Tema terang/gelap otomatis mengikuti sistem, aksen kuning (#FFD60A)
- HLS (.m3u8) dan DASH (.mpd) via Media3 ExoPlayer
- Landscape = layar penuh otomatis

Buka folder ini di Android Studio (Ladybug atau lebih baru), Sync, lalu Run.
minSdk 26, targetSdk 35.

## Fitur UI
Beranda (hero + baris rekomendasi), Cari (judul / tempel link), Koleksi (disimpan di memori sesi), layar pemutar dengan detail.
